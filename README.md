# Kata 1 - IntelliJ IDEA

## Objetivo

Microproyecto Java realizado para practicar el uso de IntelliJ IDEA, Git y GitHub, incluyendo creación, ejecución, depuración y refactorización.

## Requisitos

* JDK 27
* IntelliJ IDEA
* Git

## Ejecución

Copiar el enlace de este repositorio y crear un proyecto en File>New>Project from version control. Ahí se pega la url del repositorio y se da a clonar. Una vez tenemos el proyecto abierto, se abre el main y se ejecuta con Mayus-F10.

## Estructura

* `Main.java`: punto de entrada del programa.
* `Person.java`: clase de dominio con su atributo "name", constructor, y getter.

## Git

El desarrollo se realizó en la rama `develop` haciendo modificaciones en la clase Person y posteriormente se integró en `master`.

Se realizaron commits correspondientes a la creación, implementación y limpieza/documentación del proyecto.
